Cuan Quest ("aplikasi") dikembangkan oleh [NAMA PENGEMBANG]. Halaman ini menjelaskan bagaimana aplikasi menangani informasi Anda.

## 1. Data yang disimpan
Aplikasi tidak mengumpulkan, mengirim, atau menjual data pribadi. Nama karakter, progres permainan, dan pengaturan **hanya disimpan di perangkat Anda**.

## 2. Koneksi internet
Versi saat ini dapat dimainkan sepenuhnya offline dan tidak mengirim data ke server mana pun.

## 3. Iklan
Versi mendatang dapat menampilkan iklan opsional (*rewarded ads*) dari pihak ketiga seperti Google AdMob. Jika fitur tersebut aktif, penyedia iklan dapat memproses pengenal perangkat (misalnya ID iklan) dan data penggunaan sesuai [Kebijakan Privasi Google](https://policies.google.com/privacy). Kebijakan ini akan diperbarui dan persetujuan akan diminta sebelum fitur iklan diaktifkan.

## 4. Anak-anak
Aplikasi ini adalah simulasi edukasi dan tidak dengan sengaja mengumpulkan data dari siapa pun, termasuk anak-anak.

## 5. Menghapus data
Anda dapat menghapus semua data kapan saja melalui **Profil > Pengaturan > Reset Data**, atau dengan menghapus aplikasi.

## 6. Uang virtual & bukan saran keuangan
Semua uang dan aset di dalam aplikasi bersifat virtual, tidak memiliki nilai nyata, dan tidak dapat ditarik. Isi aplikasi bukan saran keuangan.
